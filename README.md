# Quiz App

A simple and interactive quiz application built with React.js. The questions and answers are hardcoded, so no backend or database is required.

## Features

* Multiple-choice questions
* Hardcoded questions and answers
* Score calculation
* Next question navigation
* Quiz completion/result screen
* Simple and responsive UI

## Tech Stack

* React.js
* JavaScript
* HTML5
* CSS3
* Vite

## Run Locally

```bash
git clone https://github.com/raviraj216/quiz-app.git
cd quiz-app
npm install
npm run dev
```

Open the local URL shown in the terminal to use the application.

## Project Type

Frontend-only quiz application. Questions and answers are stored directly in the application code.
